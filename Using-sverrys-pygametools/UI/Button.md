# Button

A button can be used to run a function when pressed

Parameters:<br>
`*args`: All non-keyword arguments for the main function.<br>
`rect`: The position and size of the button.<br>
`button_color`: The color of the button.<br>
`surface`: The image/text that gets displayed on the button.<br>
`display`: Where the button gets drawn.<br>
`function`: The function that gets executed when you press the button.<br>
`rounding`: How round the edges are.<br>
`resize_surface`: If the `surface` argument gets resized to fit the button (could deform the surface).<br>
`alpha_surface`: If the `surface` argument is transparent.<br>
`center_surface`: If the `surface` argument gets drawn in the center of the button or the top-left.<br>
`**kwargs`: All keyword arguments for the main function.
