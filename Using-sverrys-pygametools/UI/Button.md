# Button

A button can be used to run a function when pressed

Parameters:
`*args`: All non-keyword arguments for the main function
`rect`: The position and size of the button.
`button_color`: The color of the button.
`surface`: The image/text that gets displayed on the button.
`display`: Where the button gets drawn.
`function`: The function that gets executed when you press the button.
`rounding`: How round the edges are.
`resize_surface`: If the `surface` argument gets resized to fit the button (could deform the surface).
`alpha_surface`: If the `surface` argument is transparent.
`center_surface`: If the `surface` argument gets drawn in the center of the button or the top-left.
`**kwargs`: All keyword arguments for the main function.
