# Sverrys PygameTools
Sverrys PygameTools is a wrapper for the library "pygame" that adds a basic runtime and UI.runtime functions named "frame" and "tick":

How to use:<br>
To use Sverrys PygameTools you must install it from github by executing this command
in your terminal:
`python3 -m pip install git+https://github.com/Sverryboiii/PygameTools.git`.<br>
This will install all the file from the directory `sverpykit`.
